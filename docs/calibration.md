# 标定与参数配置

## 两点标定

先 `STOP`，断开负载电源，接好传感器，等原始 ADC 稳定。`GET` 的 `raw` 两项依次是土壤、光照；OLED 也显示原始计数。标定值不是软件默认值的确认，需要用你的实物采集。

1. 土壤：在你的干燥参考介质中测 `dry`；在相同土壤充分湿润且排去自由水的参考状态测 `wet`。保持插入深度、供电和等待时间一致。不要把模块整个浸水。
2. 光照：在预定暗环境测 `dark`，在预定亮环境测 `bright`，保持传感器角度一致。不要把近距离手电读数当作某种植物最佳照度。
3. 每个端点须为 100–4000，两端至少相差 200。可同时支持输出随湿度/光照正向或反向变化的模块。
4. 在手动、实际输出和待执行请求均为 0 时发送：

```text
STOP
CAL SOIL <dry原始值> <wet原始值>
CAL LIGHT <dark原始值> <bright原始值>
CFG
SAVE
```

尖括号内容要替换成整数，不是原样输入。`OK CAL RAM` 表示只改了内存；必须收到 `OK SAVED` 并重启检查 `cal=3`。重新上电仍是手动输出归零，需要主动 `MODE AUTO`。

映射公式是 `(raw-zero)/(hundred-zero)×100`，结果夹在 0–100；ADC 当前或滤波结果接近电源轨时判无效。土壤与光照的“%”只反映选定端点间的相对位置，跨盆、跨介质、跨传感器不能直接比较。落在正常电压范围内的漂移/断线不一定能被发现。

## 默认阈值

| 参数 | 默认值 | 含义 |
|---|---:|---|
| TEMP_ON / TEMP_OFF | 300 / 280 | 30.0℃开风扇，28.0℃关闭温度请求 |
| SOIL_ON / SOIL_OFF | 35 / 45 | ≤35%请求灌溉，≥45%解除请求 |
| LIGHT_ON / LIGHT_OFF | 25 / 40 | 暗到25%开灯，亮到40%关灯 |
| SHADE_ON / SHADE_OFF | 80 / 65 | 亮到80%遮阳，降到65%打开 |
| CO2_ON / CO2_OFF | 1500 / 1200 | CO₂通风请求与蜂鸣提示回差，ppm |
| PUMP_MS | 3000 | 每次连续运行上限，500–5000ms |
| COOLDOWN_MS | 60000 | 两次浇水最小停止间隔，30000–600000ms |

阈值范围和相互关系由 `plant_config_valid()` 校验。温度开阈值 5–60℃，回差至少0.5℃；土壤开阈值5–90%，关阈值最多95%，回差至少5%；光照顺序满足 `LIGHT_ON+5≤LIGHT_OFF`、`LIGHT_OFF+5≤SHADE_OFF`、`SHADE_OFF+5≤SHADE_ON≤99`；CO₂关阈值≥400、开阈值≤5000、回差≥100。每次修改整个配置仍须合法，必要时先修改外侧阈值。

```text
STOP
THRESH TEMP_ON 320
THRESH TEMP_OFF 290
THRESH PUMP_MS 1000
CFG
SAVE
```

四键菜单只修改阈值；传感器端点标定使用串口指令。`DEFAULTS` 恢复内存默认值并清除标定标志，不会自动写 Flash。所有配置保存只在显式 SAVE 时发生，避免每次按键都擦写 Flash。

先用量杯在无植物的台架测流量：记录真实持续时间与排水体积，估算单脉冲水量，再减少泵时长。自动脉冲会在土壤仍干、传感有效且冷却结束后重试，但累计预算会限制频度。默认阈值不适合直接无人看护长期运行。
