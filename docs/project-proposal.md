# 项目说明（按当前实现修订）

## 项目定位

本项目面向课程设计和小型盆栽台架，使用STM32F103C8T6实现多参数采样、阈值控制及近距离蓝牙交互。交付由固件、电脑控制台、参考接线、构建文件、自动测试和实物验收方案构成。当前没有开发板/模块实物，不能把软件交付写为已制成原型机。

原计划书提出的节水、节电、植物存活率、成本优势、市场规模和商业可行性需要独立证据，本版本不填入未经测量的百分比、销量、收入或采购报价。原计划书里的“已完成原型、验证稳定运行”等表述不作为本项目事实。

MCU内部时钟选择64MHz，芯片最大72MHz不等于本项目实际配置。应用使用CMSIS寄存器接口，便于观察外设配置；没有混入其他工程的应用代码。

## 交互和数据

OLED显示当前模式、UTC时间/上电时长、传感值、实际软件输出、水位和故障标志；按键用于切模式、直接操作与调阈值。手机使用现成SPP串口工具，电脑提供项目自己的Tk控制台。电脑可记录CSV，但没有设备端历史数据库。

土壤和光照须针对实际模块、介质和位置进行双点标定。测量结果是相对比例，植物需求应结合种类、盆体、蒸散与水路实测确定。CO₂只做监测、提示及自动模式下的通风请求，未实现施肥或CO₂注入。

## 实物阶段计划

| 阶段 | 任务 | 进入下一阶段的证据 |
|---|---|---|
| A | 采购与无负载检查 | 型号、供电、电平和针脚照片/检查记录 |
| B | 主控/传感器/显示/蓝牙 | H01–H09通过，保存原始日志 |
| C | MOSFET及执行机构 | H10–H17通过，电流、时延、水量及结构行程记录 |
| D | 掉电、RTC和异常注入 | H18–H20通过，失败及修复记录 |
| E | 长时台架与真实盆栽对照 | H21及后续对照数据；预先定义样本、周期、光照/供水条件 |

采购进度、模块到货与实际故障未知，因此不虚构已完成日期。应在每阶段验收后更新项目状态，并保留失败记录。任何“节水”结论需要与可比的基线方案、相同植物和相同环境对照；软件演示曲线不能替代该实验。
