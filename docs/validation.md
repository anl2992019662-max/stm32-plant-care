C本机测试由官网Zig 0.15.2提供的本机C编译器构建，断言明确开启；不是用Python重新写一份控制规则后测试自己。Python的演示通过适配器调用同一C源码。软件演示绕过CO₂预热和实体标定，只注入数据和时间。

Keil工程的文件路径、源码集合和scatter引用另有一致性检查。**uVision图形界面批量构建在当前环境异常退出，原因未定位，不把该路径列为已验证成功。** 上表成功构建来自已实际运行的 `tools/build_keil.py`，直接调用同一安装中的官方Arm编译器和连接器。首次使用Keil图形界面时仍应核对本机工具链、Device Pack与工程设置；可以直接使用已验证的脚本构建。

GitHub Actions文件只配置了Linux便携C/协议测试及交付完整性检查。首次在线运行前不宣称CI已通过，也不在CI中模拟真实硬件或分发商业编译器。
