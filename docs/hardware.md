# 硬件参考接线

这是基于模块的台架原型方案，未装配实测，不是可直接投产的 PCB。先核对所购模块丝印、原厂数据手册和极性；接口表与 `firmware/src/board.c` 一致。

## 引脚

| STM32 引脚 | 连接 | 电平 / 备注 |
|---|---|---|
| PA0 | 电容式土壤模块 AO | ADC1_IN0，0–3.3V，传感器用 3.3V 供电 |
| PA1 | 模拟光照模块 AO | ADC1_IN1，0–3.3V，3.3V 供电 |
| PB5 | DS18B20 DQ | 外接 4.7kΩ 上拉至 3.3V；VDD=3.3V，禁止寄生供电 |
| PA2 | CO₂ Rx | USART2_TX→传感器 Rx |
| PA3 | CO₂ Tx | USART2_RX←传感器 Tx；3.3V TTL |
| PA9 | HC-05 Rx | USART1_TX；3.3V TTL |
| PA10 | HC-05 Tx | USART1_RX；3.3V TTL |
| PB6 / PB7 | OLED SCL / SDA | 软件 I²C，地址 0x3C，SSD1306 128×64，3.3V 上拉 |
| PB0 | 水泵 MOSFET Gate 电阻 | 高电平开；不能接水泵本体 |
| PB1 | 风扇 MOSFET Gate 电阻 | 高电平开 |

## 负载驱动（四路高电平开启）

每路：GPIO→100Ω→AO3400A Gate，Gate→10kΩ→GND，Source→功率 GND，Drain→负载负端，负载正端→其额定 5V 电源。水泵、风扇及磁性蜂鸣器并联续流二极管，**阴极接 +5V，阳极接 Drain**。二极管、电线、接插件和保险丝必须按实际启动/堵转电流选型。AO3400A SOT-23 的焊盘散热不能直接按数据手册的绝对最大电流使用。[原厂参数](https://www.aosmd.com/sites/default/files/res/datasheets/AO3400A.pdf)

推荐先使用做好的、明确支持 3.3V 驱动且带下拉/续流保护的 MOSFET 模块。部分标称“低电平触发”的继电器模块与本固件极性相反，不能直接替换。MCU 的 I/O、3.3V 稳压器和 ST-Link 不能为水泵/舵机/灯供电。

灯必须是自带限流的 5V 恒压 LED 模块，不是裸 LED；若使用恒流灯板，应重新设计驱动。参考泵和风扇为 5V 小功率直流负载，采购后先测启动电流。本方案不连接市电。

## 电源和布线

- 外部稳定 5V，分成传感器/主控支路与执行机构支路，单点共地；负载电流不要经过 ADC 的地线或面包板细跳线回流。
- 5V/4A 可作为小功率台架的供电设计起点，实际容量必须按所购水泵堵转、舵机启动、灯和风扇峰值之和留余量，不能把这一标称值当作已验证预算。各支路设合适保险丝和电源开关。
- 舵机旁参考放 470μF 电解及 100nF 陶瓷，CO₂ 旁参考放 100μF及100nF，主控/传感器附近去耦；电容只能缓冲，不能弥补不足的电源。检查极性和耐压。
- MH-Z19B 供电为 4.5–5.5V；MH-Z19C 要求 5.0±0.1V。信号是 3.3V TTL。C 型尤其需要在负载启动时实测其供电；不得用 3.3V 给 CO₂ 模块供电。
- B 型已由厂家标为停产。新采购优先核对 C 型正规来源、测量范围及最新版手册。本固件使用 `0x86` 浓度查询及校验，保守等待 180 秒；未验证其他克隆或其他 CO₂ 传感器协议。
- HC-05 裸模块和带稳压底板的供电要求不同；核对实物再接 VCC，UART 均按 3.3V 接。先确认数据模式 UART 波特率为 9600，不能把 AT 模式参数当作数据模式参数。
- OLED 用 3.3V 供电，核对板载上拉接向 3.3V。两路 ADC 一律不得超过 3.3V。可在 ADC 输入串 1kΩ、引脚侧对地并 100nF，并核对采样建立时间。

传感器与电路板应远离水滴和冷凝；本版未实现防水外壳。土壤模块只插入规定探测区域。水管出口避免虹吸；软件停泵不能阻止虹吸或机械漏水。

## 舵机和浮球

先卸下舵机连杆，使用受限行程验证 1000/1500 μs 对应实际角度，再装遮阳结构。这个设置不保证每个 SG90 恰好对应 0°/90°，也不能判断机械到位。堵转会升温、过流；需要按机构调整 `SERVO_OPEN_US` / `SERVO_SHADE_US` 并重新编译。

浮球须安装成“水量足够闭合，缺水断开”，并用万用表实测。未接浮球时水泵被禁止。台架不得长期短接来代替水位检测。开关短路不能被本软件识别；缺流、堵管和泵空转没有完整闭环检测。首次浇水必须有人观察。
