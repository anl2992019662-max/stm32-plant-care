# 蓝牙串口协议 v1

HC-05 数据口接 USART1，UART=9600、8N1、无流控。手机/电脑通过经典蓝牙 SPP 连接。只接受大写 ASCII 指令，空格分隔，末尾 LF 或 CRLF。命令内容最多95字符，非法字节或超长行丢弃到换行。不要高速循环发送，通常每秒1条指令即可。

## 指令

| 指令 | 作用 / 条件 |
|---|---|
| `HELP` | 简短帮助 |
| `GET` | 请求一帧 JSON 遥测；固件还会每2秒主动推送 |
| `CFG` | 返回阈值、端点和标定标志 |
| `STOP` | 任何模式下撤销全部输出，进入手动 |
| `MODE MANUAL` | 撤销输出，交给本地按键 |
| `MODE AUTO` | 两项标定完成才接受，撤销旧请求后交给自动控制 |
| `MODE REMOTE` | 撤销输出，开始蓝牙控制租约 |
| `PING` | 只在 REMOTE 有效，刷新10秒租约，回复 `OK PONG` |
| `SET FAN 0/1` | REMOTE 下请求风扇关闭/开启 |
| `SET PUMP 0/1` | REMOTE 下请求水泵；仍受水位、采样、标定、时长和预算限制 |
| `SET LAMP 0/1` | REMOTE 下请求补光灯 |
| `SET SHADE 0/1` | REMOTE 下请求遮阳/打开；遮阳时撤销灯请求 |
| `THRESH <名称> <无符号整数>` | 手动且输出/请求均为0；见标定文档 |
| `CAL SOIL <dry> <wet>` | 土壤双点标定，只在手动空闲 |
| `CAL LIGHT <dark> <bright>` | 光照双点标定，只在手动空闲 |
| `SAVE` | 手动空闲时保存到 Flash，回复 `OK SAVED` 或 `ERR FLASH` |
| `DEFAULTS` | 手动空闲时恢复内存默认值、清除标定；不自动保存 |
| `TIME <Unix秒>` | 手动空闲设置 RTC UTC，范围2020-01-01至2099-12-31 |

`OK REQUEST` 只表示语法和模式接受了执行请求，不表示水泵等已经启动。读 `out` 判断实际软件输出；实际电机是否运转仍需观察/测量。受阻的手动泵请求会被撤销，条件恢复后须重新发送；自动模式会按规则再次判断。重复 `SET PUMP 1` 不会延长本次计时，更改模式也不清除冷却间隔和预算。

只有有效 REMOTE 下的 PING、SET 及新选择 REMOTE 会刷新租约；GET、CFG、错误指令不刷新。每秒发送 PING 是推荐用法。10秒失联进入手动且输出归零，不会自动回 AUTO。手机工具须配置循环心跳，或在10秒内手动操作。断开前发送 STOP。

示例（逐行发送）：

```text
MODE REMOTE
SET FAN 1
PING
GET
SET FAN 0
STOP
```

## 遥测

```json
{"v":1,"ms":182000,"epoch":0,"mode":1,"t_dC":250,"soil":60,"light":50,"co2":700,"raw":[2100,2000],"valid":15,"cal":3,"out":0,"fault":0,"water":1,"pump_ms":0,"io_errors":0}
```

这是格式示例，不是实测记录。

| 字段 | 单位 / 含义 |
|---|---|
| v | 协议版本 |
| ms | 上电毫秒计数，约49.7天回绕，时差按无符号运算 |
| epoch | RTC Unix秒，0=未设/不可用 |
| mode | 0手动、1自动、2蓝牙 |
| t_dC | 0.1℃整数，251=25.1℃；无效为null |
| soil / light | 标定后的相对百分比；无效或未标定为null |
| co2 | ppm；预热/无效为null |
| raw | `[土壤ADC,光照ADC]`，用于标定，不能单独证明传感器健康 |
| valid | 位0温度、1土壤原始采样、2光照原始采样、3CO₂有效 |
| cal | 位0土壤已标定、位1光照已标定；3=全部完成 |
| out | 位0风扇、1泵、2灯、3遮阳；1=逻辑开启 |
| water | 1=浮球闭合，0=缺水/未接 |
| pump_ms | 当前运行小时的泵累计毫秒，复位清零 |
| io_errors | 驱动/收发累计错误计数，仅用于诊断 |

`fault` 位掩码：1温度无效、2土壤无效、4光照无效、8CO₂预热/无效、16缺水、32远程租约超时、64浇水预算耗尽、128未全部标定。多个值相加，如144表示未标定及缺水。CO₂预热期间 fault=8但不因此发出故障蜂鸣。其他故障短鸣，CO₂高浓度有独立节奏提示。

应同时处理普通 `OK/ERR` 文本和 JSON；不能把每一行都当JSON。串口可能把一行分成几次读取，接收端须按LF重组并限制缓存。

## 配置格式

CFG 按以下顺序返回：

```text
CFG TEMP=on,off SOIL=on,off LIGHT=on,off SHADE=on,off CO2=on,off PUMP=ms COOL=ms CAL=dry,wet,dark,bright,flags
```

命令不提供网络认证或加密层。只在可信的已配对设备之间使用，按具体 HC-05 手册更改配对凭据。代码和仓库不保存个人蓝牙 PIN、账户密码或网络密钥。
