# 控制策略与按键

## 模式

上电始终手动、请求清零。进入新模式会撤销旧输出，不重置泵冷却/累计预算。配置参数可以跨上电保存，运行模式和输出不能跨上电恢复。

| 模式 | 输出来源 | 退出/失效行为 |
|---|---|---|
| 手动 | K3开启、K4关闭当前选中设备 | 30秒无执行操作，全部归零 |
| 自动 | 传感数据和可配置回差 | 切模式/STOP归零；相应传感无效撤销其自动请求 |
| 蓝牙 | SET指令 | 10秒无心跳/有效控制，归零并回手动 |

自动风扇取温度请求与CO₂请求的“或”；某个传感器无效不会阻止另一个有效传感器请求通风。手动/蓝牙可直接控制风扇/灯/遮阳，泵在所有模式中始终受许可约束。高 CO₂ 提示在所有模式有效，但不会擅自在手动模式启动风扇。

## 浇水流程

土壤低于开启阈值产生自动浇水需求；水位正常、土壤采样新鲜且已标定、冷却到期、预算未耗尽时才启动。达到湿度关闭阈值、超过单次时长、水位断开或土壤数据无效，都会停泵。停泵后至少等待冷却间隔；仍干时才允许下个自动脉冲。默认3秒/60秒/每运行小时15秒。

泵预算在固定运行小时边界重置，复位会清零。模式改变不能清预算或冷却。反复发送 ON 不能重置正在运行的起点；手动请求若被互锁阻挡会撤销，不在条件恢复后突然执行。供电反复复位、虹吸、管路堵塞和电机机械故障不能由这些软件计时规则完全解决。

实际停止延时受主循环及驱动耗时影响，硬件验收要求测量并记录，不能把配置的3000ms当作机械水流恰好3000ms。看门狗是程序卡死后的补充，不能替代水泵支路电源开关、外部下拉及有人监督的初次测试。

## 传感器

- ADC每100ms采一次；填满5点后用中值，当前采样或中值处于近电源轨则无效。相对量允许正向/反向标定。正常范围内的漂移仍可能漏检。
- DS18B20每轮先启动转换，等待800ms再检查完成位并读9字节scratchpad；CRC通过才更新。支持负温度及分辨率无效位处理。采用外部供电、单设备 Skip ROM；多设备不直接兼容。
- MH-Z19每5秒查询，1秒响应窗口、帧头和校验检查；上电180秒预热；数据超过12秒不更新则失效。不会自动发送零点标定或修改自校准设置；温室高CO₂环境是否适合自校准，须按具体模块手册人工确认。
- 温度超过3秒、ADC超过1.5秒未更新也会被控制核心判过期。无效值输出null，不把旧值显示成新测量。

## 四键

| 按键 | 短按 | 长按（1.2秒） |
|---|---|---|
| K1 PB13 | 手动→自动→蓝牙→手动；未标定时跳过自动 | STOP并回手动 |
| K2 PB14 | 切换当前设备；设置页切下一参数 | STOP并进入/退出设置页 |
| K3 PB15 | 手动开启选中设备；设置页增加参数 | 无额外操作 |
| K4 PA8 | 手动关闭选中设备；设置页减少参数 | 手动空闲时保存配置 |

设备选择顺序：风扇、水泵、补光灯、遮阳。按键30ms去抖。蓝牙模式下K3/K4不直接执行负载，先用K1切到手动。设置页修改失败时维持原值，通常是回差/阈值顺序限制；界面数值不变即可识别。保存结果经串口OK/ERR反馈，必要时重启核对CFG。

## 调度

无RTOS。SysTick提供毫秒，DWT提供微秒延时；UART使用中断环形缓存，蓝牙发送入队而非整帧阻塞；温度转换期间主循环继续工作。OLED每次只刷新一页，失联后间隔重试；CO₂查询发送等少量底层操作有有界等待。硬件驱动仍需逻辑分析仪验证时序和主循环最长周期。
